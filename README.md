# Insurance ML

Практический учебный проект по машинному обучению: прогнозирование
медицинских расходов с использованием Python и Scikit-learn.

В проекте исследуется датасет `insurance.csv`, выполняется первичный
анализ данных, предобработка признаков и обучение нескольких моделей
линейной регрессии с регуляризацией.

## 🎯 Цель проекта

Научиться строить базовый ML-пайплайн для задачи регрессии:

-   исследовать исходные данные;
-   проверить наличие пропусков;
-   изучить корреляции и распределения признаков;
-   подготовить числовые и категориальные признаки;
-   разделить данные на обучающую и тестовую выборки;
-   масштабировать числовые признаки;
-   кодировать категориальные признаки;
-   обучить Linear Regression, Ridge и Lasso;
-   подобрать `alpha` с помощью cross-validation;
-   оценить качество моделей с помощью R² и RMSE.

## 📊 Датасет

Используется датасет медицинских расходов `insurance.csv`.

Основные признаки:

  Признак      Описание
  ------------ -----------------------------------------
  `age`        Возраст
  `sex`        Пол
  `bmi`        Индекс массы тела
  `children`   Количество детей
  `smoker`     Статус курения
  `region`     Регион
  `charges`    Медицинские расходы, целевая переменная

Целевая переменная:

``` text
charges
```

Модель пытается предсказать медицинские расходы на основе характеристик
человека.

## ⚙️ Предобработка данных

Для подготовки признаков используется `ColumnTransformer`.

### Числовые признаки

``` python
numeric_features = ["age", "bmi", "smoker"]
```

Для них применяется:

``` python
StandardScaler()
```

Стандартизация приводит признаки к сопоставимому масштабу.

### Категориальный признак

``` python
categorical_features = ["region"]
```

Для него применяется:

``` python
OneHotEncoder(handle_unknown="ignore")
```

В результате категориальный признак `region` преобразуется в набор
бинарных признаков.

Важно: `fit_transform()` применяется только к обучающей выборке, а для
тестовой используется `transform()`. Это позволяет избежать утечки
данных.

## 🧠 Модели

В проекте рассматриваются три модели:

### Linear Regression

Базовая линейная регрессия без L1/L2-регуляризации.

### Ridge Regression

Линейная регрессия с L2-регуляризацией.

Для подбора параметра `alpha` используется:

``` python
RidgeCV(alphas=[0.1, 1.0, 10.0, 100.0], cv=3)
```

Найденное значение:

``` text
alpha = 10.0
```

### Lasso Regression

Линейная регрессия с L1-регуляризацией.

Для подбора `alpha` используется:

``` python
LassoCV(alphas=[0.1, 1.0, 10.0, 100.0], cv=3)
```

Найденное значение:

``` text
alpha = 10.0
```

## 🧪 Метрики

### R²

`R²` показывает, насколько хорошо модель объясняет вариацию целевой
переменной относительно базового предсказания средним значением.

Чем ближе значение к `1`, тем лучше модель объясняет данные в рамках
этой метрики.

### RMSE

`RMSE` (Root Mean Squared Error) показывает средний масштаб ошибки
предсказания в единицах целевой переменной.

В данном проекте целевая переменная --- `charges`, поэтому RMSE также
выражен в единицах медицинских расходов из датасета.

Используемые линейные модели предполагают достаточно простую зависимость
между признаками и целевой переменной и не предназначены для полного
описания всех факторов, влияющих на медицинские расходы.
